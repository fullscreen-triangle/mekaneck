\section{Cardiac-Referenced EEG Phase Analysis Protocol}

\subsection{Equipment}
64-channel EEG system, 3-lead ECG, pulse oximetry, atmospheric oxygen analyser.

\subsection{Procedure}
\begin{enumerate}
  \item Record simultaneous EEG and ECG at $\geq 2048$~Hz sampling rate.
  \item Identify R-peaks in ECG as master phase reference events.
  \item Compute phase-locking value (PLV) between cardiac R-peak times and each EEG channel.
  \item Apply hierarchical phase decomposition across 13 oscillatory scales.
  \item Compute confluence metrics: PLV, $\mathcal{C}_{\mathrm{confluence}}$, $\mathcal{S}_{\mathrm{equilibrium}}$.
\end{enumerate}
