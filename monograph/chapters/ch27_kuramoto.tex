\chapter{Kuramoto Oscillators and Biological Phase Computing}
\label{ch:kuramoto}

\papernote{Source paper: \emph{Kuramoto Oscillator Phase Computing} --- \texttt{docs/computing/kuramoto-oscillator/}}

\begin{chapterabstract}
The Kuramoto model of coupled oscillators provides the mean-field description of phase synchronisation in biological neural networks. This chapter derives the Kuramoto dynamics from the categorical completion framework---the coupling function emerges from the requirement that phase differences encode categorical distance---and extends the model to handle the hierarchical multi-scale synchronisation required by the cardiac-referenced perception framework of Chapter~\ref{ch:perception_flux}. The biological phase computing paradigm is then constructed: computation is the controlled manipulation of synchronisation patterns across the oscillator network.
\end{chapterabstract}
